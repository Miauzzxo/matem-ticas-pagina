# matem-ticas-pagina
matematicas prueba

Descripcion del proyecto:
este proyecto funciona para para identificar y visualizar distintos tipos de funciones mediante la generacion de valores aleatorios que van del -3 al 3

la pagina permte reconocer las funciones lineales afines y constantes y al salir ambos generadores con 0 no se genera ninguna funcion

la funcion lineal contiene f(x)=bx donde el termino independiente es cero
funcion afin:esta contiene f(x)=bx + c donde existe el temino idependiente distinto de cero 
funcion constante:esta contiene f(x) = c donde el coeficiente de x es cero 
sin funcion generada:esta ocurre cuando ambos generadores coeficientes son 0

estructuras de la pagina:
HTML:estructura y contenido de la pagina
CSS:diseño colores estilo y distribucion de elementos
JavaScript:generacion de numeros aleatorios clasificacion de funciones e interaccion con los botones y el generador


Funciones de la pagina: 
la pagina utiliza JS para generar valores aleatorios entre -3 y 3

con esos valores identifica que tipo de funion correspondey muestra el resultado en pantalla tambien representa la funcion en un plano cartesano para facilitar su comprension


como utilizar pagina web:
1-abrir la pagina en el navegador
2-presionar el boton de generar para generar una funcion
3-Observar los coefiientes generaos 
4-Revisar que tipo de funcion se ha identificado
5-Observar su representacion en el plano Cartesiano
